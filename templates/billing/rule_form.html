Rule kinds

  • Linked accounts: whole accounts; exact from stored facts.
  • Tag / cost category: customer-wide, using a scoped cached AWS query grouped by linked account; whole-account claims by other projects are excluded exactly.
  • Accounts + tag/category: the tag or category rule restricted to chosen accounts.

Rules over the same key must use disjoint values; rules over different keys may only overlap through disjoint account scopes. Shared or untagged charges stay in the Unallocated / shared remainder; nothing is allocated proportionally.
